# Distance Program

## Description
This program calculates the distance between two points using a math library.

## How To Run
1. Open the program file in OnlineGDB.
2. Run the program.
3. Enter values for x1, x2, y1 and y2.
4. Check the distance displayed in the screen.

## Input Needed
- x1
- x2
- y1
- y2

## Sample Output
Enter x1: 6
Enter x2: 7
Enter y1: 2
Enter y2: 3
The distance between the two points are : 1.41
